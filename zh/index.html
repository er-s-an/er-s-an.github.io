04 / 作品背后的这个人

一半是系统，
一半凭直觉。

Caesar / Jiachen Xie / 谢佳辰

既在意系统怎么运行，
也在意人怎么使用。

大家通常叫我 Caesar。我在香港城市大学读书，也是 MAKEBOOK 的 CTO，主要做 AI Agent、创作工具和游戏相关的系统。我喜欢把一个点子从头做到尾：它解决什么问题，底层如何运转，最后又怎样被人使用。

一件外套的剪裁、一行字的疏密、一次交互的手感，都会让我多看一眼。我也把这种在意带进代码里：让作品有性格，让按钮把自己的活干好。

AI 研究与工程实习

我希望加入月之暗面（Moonshot AI）的 Kimi 团队实习，也对其他顶尖 AI 实验室的机会感兴趣。最想做的是大模型后训练，尤其是 Agent 评测和训练环境建设。

研究方向与代表作品

我在找 AI 研究工程实习（Research Engineer Intern）和 AI Agent 工程实习机会。希望从真实的 Web 和游戏开发场景出发，为 Coding Agent 设计可执行的任务和评测标准。实习地点不限，愿为合适的机会调整学业安排。

大模型 Agent 评测与电脑操作

在Kimi K3 实测中，我用游戏原型和视频剪辑任务比较完成度、视觉反馈和 Token 成本。腾讯混元 HY4 实测覆盖长程电脑操作，以及从参考图生成可玩网页游戏的任务。

Agent Harness 与工具调用

在腾讯游戏光子工作室群实习时，我搭建了游戏内的 ReAct Agent 层，把角色移动、建筑放置封装成 MCP 兼容动作，并独立开发了 Godot 编辑器插件原型，把生成模型 API 接进游戏资产工作流。

Web 与游戏任务环境

在《看山任意门》里，我们做了把故事编译成游戏的管线、结构校验和采用确定性规则的交互运行时。项目入围知乎黑客松 S2 全国总决赛。

多模态 RAG 开源贡献

我在RAG-Anything 和 LightRAG的贡献包括减少文档入库时的模型调用，以及让 LightRAG 发现已安装的自定义分块插件。
